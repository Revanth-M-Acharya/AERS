# Public Headers Directory
Organized under the top-level namespace `aegis`:
* `aegis/common/`: Common types, error codes, constants, and geometric primitives.
* `aegis/core/`: Interfaces for dispatch, fleet management, routing, and priority scheduling.
* `aegis/edge/`: Interfaces for ambulance telematics and roadside traffic controllers.
* `aegis/network/`: Transport abstractions (MQTT, sockets, IPC).
* `aegis/safety/`: Watchdog, logging, and safety supervisor interfaces.
