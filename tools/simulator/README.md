# Multi-Node Simulation Suite
Provides independent mock engines for hardware-in-the-loop and headless simulation:
* `gps_simulator/`: Generates NMEA-0183 sentences over virtual PTY ports.
* `traffic_simulator/`: Emulates an array of signalized intersections and relays.
* `vitals_simulator/`: Generates physiological patient data waveforms.
* `dispatcher_simulator/`: Ingests simulated 911 distress calls.
* `ambulance_simulator/`: Virtual ambulance vehicle tracking and telemetry sink.
