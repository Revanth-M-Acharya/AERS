# Operational & Automation Scripts
* `build.sh`: Builds the native host or cross-compiled targets.
* `run_simulation.sh`: Spawns the full multi-node testbed simulation on a single host.
* `deploy_pi.sh`: Deploys compiled binaries to target Raspberry Pi edge nodes via SSH/SCP.
* `flash_qnx.sh`: Automates packaging and network deployment to QNX Neutrino target hardware.
